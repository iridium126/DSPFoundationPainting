# 戴森球地基画模组 DSPFoundationPainting
本项目是《戴森球计划》的模组，提供了一键铺设地基画的功能。

## 项目结构
- Calculator  
  用于生成纹理图片的程序。  
  根据在图形界面选择的图片，输入的**经纬度**和地基画直径对应的**圆心角**，生成模组使用的纹理图片。  
  **经纬度**决定地基画铺设后的中心位置，**圆心角**决定地基画的大小。Calculator会保存每次计算产生的中间数据至**data**文件夹，下次使用相同的经纬度和圆心角配置时，直接读取数据。
- Painter  
  地基画模组。  
  负责在游戏中自动铺设地基画和自动加载已有的地基画。  
  按下**一键铺设地基画**按钮，在弹出的文件选择框中选择Calculator生成的纹理图片，就能自动在当前行星上铺设这幅地基画。
